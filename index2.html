⚠️ Si vous souhaitez faire une mise à jour manuelle de votre Passerelle, vous devez effectuer les manipulations suivantes :
⚠️ Navigateur non compatible. Cette page nécessite Google Chrome ou Microsoft Edge (version récente). Firefox et Safari ne supportent pas l'API Serial.
💻 Pilotes USB requis (Windows uniquement) Avant de commencer, installez les pilotes USB pour que Windows reconnaisse la passerelle. Installez les deux — ils coexistent sans problème.
⬇️ Pilote CH340 (le plus courant) ⬇️ Pilote CP2102 (Silicon Labs)
🐧 Linux détecté — aucun pilote requis Linux reconnaît nativement les modules ESP32. Utilisez directement Google Chrome ou Microsoft Edge pour flasher.
1
Sortez le module ESP32 du boîtier Tirez doucement sur le module ESP32 pour l'extraire du boîtier (voir photo ci-dessous).

📷 Tirez sur le module ESP32 pour le sortir du boîtier

2
Branchez le câble USB sur l'ESP32 Connectez le câble USB-C directement sur le module ESP32 sorti du boîtier.
3
Cliquez sur « Flasher la passerelle » Sélectionnez le port série dans la fenêtre qui s'ouvre, puis attendez la fin (~2 min). Remettez ensuite l'ESP32 dans le boîtier.
🚨 NE COCHEZ PAS la case "Erase device" — cela effacerait la calibration de la balance et tous les réglages de la passerelle.
